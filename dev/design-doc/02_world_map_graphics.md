- A working artifact already exists outside this design doc: the world grid was processed into a 157×114 grid at 16px/cell, with terrain codes for ocean, playable land, the Fallen Empire ruins zone, impassable external continents, and unmapped void — delivered as an HTML viewer, `elental_grid.json`, and a PNG preview.
- Open production question not yet resolved: whether to cluster the fine-grained terrain cells into coarser gameplay provinces, and how the fantasy/cyberpunk visual language (aesthetic direction, palette, UI-map conventions) should be expressed on top of that grid.
