# Elental — runnable skeleton (spec: `*__spec.md`)

Plain JS + ES modules, no bundler. `npm test` runs 33 tests with Node's built-in runner (Node >= 20).

## Launch
```
python3 serve.py            # then open http://localhost:8000/   (any static server works; file:// does not, because of fetch)
node tools/headless.mjs demo 20     # same engine, no browser: 20 turns, one summary line per turn
npm run build:data          # regenerates data/ruleset.json and scenarios/demo/*.json
```
The browser shell (`index.html`, `src/ui/debugShell.js`) is a **debug shell**, not the game UI: hex map with lenses, selected-province card, cell table,
Government card, an Orders tray (setTaxLaw, placeRequisition, setControlAllocation go through the real Action pipeline), End Turn / Run 10, history table.
It has not been exercised in a real browser yet (only syntax-checked and served over HTTP); the engine behind it is covered by the tests.

| Path | Status |
|---|---|
| `src/kernel/` | ids, scope (specificity ladder), modifiers, Allocation Dial, threshold, claims, rng, stance, derive memo, schema validator — done, tested |
| `src/engine/engine.js` | ActionRegistry, `resolveTurn` (8-step pipeline), gating + force-through, Decision Log, Scheduler — done, tested (stub polity hooks) |
| `src/modules/worldmap/` | hex grid (odd-r), edge rule (Mountain interior blocked), Regions (6-8, snapshot-and-drift), cell split/merge, read services — done, tested |
| `src/modules/economics/` | production (extraction + zone processing), Land split, Requisition, trade zones, price pass with flows, tier-first cascade, taxation, debt service, credit clearing, Ledger — first runnable version, tested on a tiny world |
| `src/modules/polity/` | grievance, compliance (voluntary + Control), opinion, awareness, prestige/Weight, fairness gap, Questions, momentum + banded rungs — first runnable version; gating/stance/cell actions are stubs |
| `src/data/loaders/`, `src/client/engineClient.js` | readPackage (Node/browser), effective ruleset, `buildState`, main-thread EngineClient (`init/submit/endTurn/runTurns/query`) — done, tested on `scenarios/demo` |
| `src/modules/polity/actions.js` | setTaxLaw, setControlAllocation, setSpendingDial, placeRequisition |
| `data/ruleset.json`, `scenarios/demo/` | shared ruleset (45 goods, 21 pools incl. 2 placeholder, 12 needs, 24 rights, 8 duties, 9 terrains) generated by `tools/buildRuleset.mjs`; demo = 14x10 grid, 2 Countries, 3 Nations, 2 Estates |
| `src/modules/administration/` | Control dial → involuntary compliance (slate, observation, emergency powers not yet implemented) |
| `scenarios/alpha/tuning.defaults.json` | 112 placeholder tuning keys (also embedded in `data/ruleset.json`) (all editable at the numbers pass) |
| `tests/` | `fixtures.js` builds a 1-Country / 1-Region / 2-Nation test world |

Not yet implemented (specified in the `__spec.md` files): War, Diplomacy, factions and cell action choice, Mobility/Demotion/Convergence,
propaganda/Teaching, minting and rituals, warehouse spoilage, Observation stamps, scenario loader/validators/Editor, worldgen stages.
